# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to [GNOMATIX Support](mailto:support@gnomatix.com).

For more information, see:
    https://youtu.be/hQqijzLPBWo?si=RYvdwR_eFbYWJr1Q

All security vulnerabilities will be promptly addressed.
