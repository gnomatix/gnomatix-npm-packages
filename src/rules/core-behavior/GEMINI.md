# Core Agent Behavior

- Be concise and direct in all communications.
- Prioritize safety and security in every tool call.
- Adhere strictly to project-specific conventions discovered in the workspace.
- When unsure, ask for clarification before taking destructive actions.

## Repository Standards
- **Commits**: Use Conventional Commits (`feat:`, `fix:`, etc.).
- **Branching**: Follow Git Flow conventions (`main`, `develop`, `feature/`).
- **Versioning**: Use `npm run release` for automated tagging and changelog generation.
