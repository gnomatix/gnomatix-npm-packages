# POSIX Conventions (Linux/macOS)

- **Command Chaining**: Use `&&` for conditional execution and `;` for sequential execution.
- **Path Separation**: Always use forward slashes `/`.
- **Shell Scripts**: Prefer `bash` or `sh` syntax. Ensure scripts have appropriate shebangs (e.g., `#!/usr/bin/env bash`).
- **Permissions**: Use `chmod +x` to ensure scripts are executable.
- **Case Sensitivity**: Be mindful that file systems are case-sensitive.
